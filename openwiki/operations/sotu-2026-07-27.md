## Naming Convention

- **Project wikis:** `<project>-wiki` — carries project-specific architecture, decisions, current state
- **Utility skills:** descriptive name (`termux-helper`, `defuddle`) — reusable knowledge that applies across projects

Project wikis never duplicate utility skill content — they reference it. A horizons-wiki entry about NPU routing says "see termux-helper Part 2," it doesn't repeat the explanation.

## Lessons Learned (Reusable)

1. **Variable fonts + Compose = pain.** `FontVariation` is `@ExperimentalTextApi`; XML `fontVariationSettings` fails silently when `usWeightClass` doesn't match. Cut static instances with fontTools.
2. **Missing glyphs fail silently.** Android substitutes a fallback face for individual missing characters. The result looks like a font-weight bug but it's a glyph-coverage bug. Check the font's cmap before trusting the render.
3. **build-apk.yml on `branches: '**'`+ shared release tag = clobber.** Any push to any branch overwrites the same`latest-debug`tag. Use`workflow_dispatch` targeting the specific branch.
4. **Multiple code versions coexist.** Always `git branch -a` before working — the active branch may not be `main`.
5. **dp not sp for brand type.** Device font-scale multiplier clips oversized sp text. dp is density-only and predictable.
6. **Termux + Hexagon = impossible.** Don't try. Route through the app.
